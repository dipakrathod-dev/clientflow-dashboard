# ⚡ ClientFlow Dashboard

ClientFlow is a modern, responsive SaaS Analytics and Client Management Dashboard designed for freelancers and small businesses to manage clients, track projects, generate invoices, and view real-time analytics.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend / Database:** Firebase Authentication, Firestore
* **Routing & State:** React Router v6, React Context API
* **Data Visualization:** Recharts
* **UI Feedback:** React Hot Toast

## 🌟 Key Features
* 🔒 **Firebase Auth:** Secure Login & Registration with Protected Routes.
* 📊 **Analytics Dashboard:** Live revenue trends and client growth tracking.
* 👥 **Client Management:** Complete CRUD operations with Firestore.
* 🌓 **Responsive UI:** Modern, dark-themed dashboard UI tailored for all screen sizes.
